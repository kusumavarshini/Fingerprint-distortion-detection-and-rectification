2. USABILITY AS CLEAN HARD NEGATIVES
================================================================================
Can existing training samples from these categories safely be used as CLEAN 
hard negatives with photometric/quality augmentation?

YES, ABSOLUTELY:
1. Ground Truth Integrity: Every image in data/split/train/ is a verified, authentic
   clean impression taken from the family split. None possess synthetic warping.
2. Label Correctness: A faint, over-inked, partial, or child print remains fundamentally
   CLEAN (Class 0). Teaching the model that these patterns belong to Class 0 directly
   targets the root cause of the 22.22% false positive rate.
3. No Contamination: Utilizing solely data/split/train/ completely prevents data leakage
   into validation or test splits. The family boundaries remain 100% clean.

================================================================================
3. RECOMMENDED V4 CLASSIFIER TRAINING-DATA DESIGN
================================================================================

To completely decouple image quality from geometric distortion, both Class 0 
(CLEAN) and Class 1 (DISTORTED) must share the SAME photometric quality distribution.

A. Binary Class Balance:
   - Target Total: 2,100 training samples per epoch (Strict 1:1 Clean : Distorted)
   - Clean (Class 0):     1,050 samples
   - Distorted (Class 1): 1,050 samples

B. Clean Class (Class 0) Composition:
   - 525 Unmodified Clean Source Images (drawn from data/split/train/)
   - 525 Quality-Augmented Clean Hard Negatives:
     * 175 Faint / Low-Contrast augmented (gamma scaling + brightness boost)
     * 175 Over-Inked / Saturated augmented (morphological dilation + local shadow pooling)
     * 175 Partial / Peripheral Cutout augmented (random cropping / masking + paper grain noise)
   - Total Clean = 1,050 samples

C. Distorted Class (Class 1) Composition:
   - Drawn from the approved V3 synthetic distortions (data/classifier_v3/train/distorted/)
   - Exact 1:1:1 Distortion Type Balance:
     * 350 Elastic Distortions
     * 350 Local Distortions
     * 350 Bending Distortions
   - Total Distorted = 1,050 samples

D. Should Quality Augmentation Also Be Applied to Distorted Samples?
   - YES, on 50% of distorted samples!
   - Why: If ONLY clean images receive quality augmentation, the model might learn
     that "clean prints have artifacts, while distorted prints are uniform."
   - Symmetrical Design:
     * In Clean:     50% standard + 50% quality-augmented
     * In Distorted: 50% standard V3 + 50% quality-augmented V3
     * This creates mathematical orthogonality between geometric distortion and
       photometric/quality variations. The CNN is forced to rely exclusively on
       ridge curvature, shear, and wave displacement fields.

E. Validation & Testing Protocols:
   - Keep V3 validation set (450 samples: 225 clean + 75 elastic + 75 local + 75 bending)
     and V3 test set (450 samples) completely frozen.
   - Dual-Objective Threshold Selection: Select threshold on validation set that
     maximizes F1 while requiring clean false positive rate <= 5.0%.
