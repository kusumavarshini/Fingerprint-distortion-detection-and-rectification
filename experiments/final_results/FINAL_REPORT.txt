FINGERPRINT DISTORTION DETECTION AND RECTIFICATION — FINAL REPORT
========================================================================

1. Project objective
Assess whether DDRNet_DIR rectification improves MINDTCT + Bozorth3 verification of synthetically distorted fingerprints against clean fingerprints.

2. Dataset and split
Family Fingerprint Dataset: 100 families, 1,500 images (512x512 source images, processed to 224x224). Family-disjoint split: 70 train / 15 validation / 15 test families (1,050 / 225 / 225 images).

3. Frozen distortion classifier
Experiment 5 test: accuracy 0.8889, precision 0.9534, recall 0.8178, F1 0.8804, ROC-AUC 0.9432 (TN=216, FP=9, FN=41, TP=184).

5. Matching methodology
MINDTCT minutiae extraction and Bozorth3 scoring. Every split has 45 identities, 450 cross-impression genuine pairs and 315 cross-family, same-member-type impostor pairs. Test identities are absent from train and validation. Thresholds use validation EER only; test labels were never used to select a threshold.

9. Conclusion
The result is reported as observed. Pixel-level geometric improvement does not by itself establish improved MINDTCT/Bozorth3 recognition. AUC and the validation-calibrated verification measures are the primary recognition evidence.

10. Limitations and future improvements
Scores are weakly separated and the test protocol has many zero/low Bozorth3 scores, so threshold accuracy is unstable; ROC-AUC is more threshold-independent. Future work should improve minutiae preservation/orientation consistency, train rectification with matcher-aware losses, evaluate additional real distortions, and use a stronger but independently validated matcher.

  The severity results below are based on DETERMINISTICALLY REGENERATED GROUND-TRUTH
  displacement fields. These were produced using the identical distortion functions and
  seeds as generate_rectification_eval.py — not from DDRNet inference. They must not
  be described as severity predictions from DDRNet.

Severity score definition (field-source-independent):
  score = mean(sqrt(dx^2 + dy^2))   [mean displacement magnitude, pixels]
  The formula applies to any displacement field — GT or predicted. The severity.py
  module accepts any dx/dy arrays; only the source of those arrays changes.

Categorical thresholds derived from training-set terciles (3,150 samples, training data only):
  Low:      mean displacement < 4.2982 px  (training P33.33)
  Moderate: 4.2982 <= mean displacement < 5.9275 px  (training P33.33 – P66.67)
  High:     mean displacement >= 5.9275 px  (training P66.67)

Severity on validation set (675 samples = 225 images x 3 distortion types):
  Field source: ground-truth displacement fields (NOT DDRNet predictions)
  Overall:  mean=5.269 px  [Low=31.3%, Moderate=35.6%, High=33.2%]
  Elastic:  mean=6.815 px  [Low=1.3%,  Moderate=27.6%, High=71.1%]
  Local:    mean=3.829 px  [Low=68.0%, Moderate=31.6%, High=0.4%]
  Bending:  mean=5.164 px  [Low=24.4%, Moderate=47.6%, High=28.0%]

Note: categorical severity correlates strongly with distortion type because
different synthetic distortion functions generate inherently different displacement
magnitudes. Elastic is predominantly High, local predominantly Low, bending spans
all three. This is documented, not treated as a limitation.
